# LINE Seed font provenance

This prototype bundles the official LINE Seed Sans EN and TH web font files from the LINE Seed website:

- https://seed.line.me/index_en.html
- EN package: `LINE_Seed_Sans_EN.zip`
- TH package: `LINE_Seed_Sans_TH.zip`

The official page states that the fonts are provided under the SIL Open Font License 1.1. The files are used locally for this prototype; they are not sold or modified. The original package release notes remain alongside the downloaded font directories.
